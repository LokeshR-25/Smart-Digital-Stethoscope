# Results

The project report documents the observed output of the Smart Stethoscope:

- Raw ADC heart-sound waveform
- Filtered 20–200 Hz waveform
- Heart-sound envelope
- BPM measurement
- CubeMonitor dashboard with BPM classification

The reported BPM during testing was approximately **70–90 BPM**, depending on the subject and measurement conditions.
